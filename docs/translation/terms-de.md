# German (`de`) binding terminology — Talmud Eser Sefirot

Every German translator reads this before the first item. It is built only from
Bnei Baruch's **official German** and counted, not remembered:

| code  | source                   | what it is                                                                                                                           |
| ----- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| **I** | `km-intro/intro.de.txt`  | _Einführung zu Talmud Esser haSefirot_ (BB's Introduction, 155 numbered sections aligned with the Hebrew)                            |
| **P** | `km-intro/pticha.de.txt` | _Einführung in die Weisheit der Kabbala_ (Pticha, 187 numbered sections aligned with the Hebrew) — **the technical-vocabulary text** |
| C     | —                        | **none**: no official German TES chapter exists in the repo                                                                          |

Counts are Python-regex matches over I and P (Unicode NFC — the Intro file is
stored decomposed, so umlauts only count after normalising — and typographic
apostrophes unified), written `form total (I.. P..)`. Hebrew↔German
correspondences were checked section by section (Hebrew §N against German §N),
not just by global frequency. 242 rows: **212 OFFICIAL**, **30 PROPOSED**.
Re-run any number with `terms/de/work/cnt.py`; the table is generated by
`terms/de/work/gen.py`, which also proves every `banned` pattern has 0 official
hits.

**Read this first.** BB's German is two registers. The Intro is plain German
prose about Tora and Providence (Tora 351, Schöpfer 211, Welt 229) and uses
almost no technical vocabulary. The Pticha carries the whole system, and its
method is **transliterate, gloss once in German, then use the Hebrew**:
„Massach (Schirm)“, „Awiut (Grobheit, Dicke)“, „Siwug de Hakaa
(Zusammenstoß)“, „Or Choser (Reflektiertes Licht)“, „Bchina Alef (Phase
Eins)“. So BB German transliterates far more than the English canon does:
Kli, Massach, Awiut, Reshimo, Siwug, Bitush, Hisdakchut, Achoraim, Yenika,
Katnut / Gadlut. Do not import the English solution.

## 0. Precedence

1. **This table binds.** Where it is silent, grep I and P for BB's form, then
   follow the scheme in §1. Report every new term you had to coin.
2. **BB's German beats the English canon.** `docs/translation-terminology.md`
   is orientation only. The big reversals are in §3.1.
3. **The lemma rule, as in English.** Inside a bolded `<b>` lemma that quotes
   the ARI, follow the pane's _phrasing_; technical terms and name spellings in
   this table never follow the pane. A lemma is just bold — no quotation marks,
   no italics: `<b>Und das Höhere Licht breitete sich aus</b>`.
4. **Never emend, never drop.** BB's German compresses citations (it renders
   `(כנ"ל באות ל"ה, עש"ה)` as „(Punkt 35)“ and drops every ד"ה, עכ"ל and
   וז"ל of the Intro). We do not: every formula gets the wording in §2.9.

### 1.3 Capitalisation, acronyms, connectors, gender

- **Nouns are capitalised anyway in German**; the rule that matters is the
  _adjective_ in fixed names: **das Höhere Licht** (80; lower-case 0),
  **der Höhere** (87), **der Untere** (23), **die Abschließende Malchut** /
  **die Paarende Malchut**, **die Höheren Welten**, **die Zehn Sefirot** (209 :
  „zehn Sefirot“ 3), **Zimzum Alef (Erste Einschränkung)**. Ordinary
  adjectives stay lower case: die untere Hälfte, das untere Hej.
- **Pronouns for the Creator are capitalised**: Er, Ihm, Sein Name, Seine
  Lenkung (BB throughout).
- **Acronyms** keep BB's mixed case, which shows the vowels; no dots, no
  hyphens: AK, AB, SaG, MaH, BoN, GaR, SaT, WaK, WaT, SA, AA, SoN, AwI,
  ISHSuT, ACHaP, GE, CHaGaT, NeHJ, NeHJM, TaNHJ, TaNHJM, CHuB, TuM, KaCHaB,
  KaCHBaD, CHaBaD, NaRaN, NaRaNCHaY, MaN, ABYA, BYA, TaNTA, RaTaS, HaWaYaH.
  Copy each exactly — `SON`, `ZON`, `VAK`, `AVI`, `AHP`, `HGT`, `NHY` are 0
  in BB and banned. **SoN and AwI take plural verbs** („SoN stiegen“ 7 : 1,
  „AwI empfingen“ 8 : 2). Expand only where the Hebrew spells the name out
  (Seir Anpin, Arich Anpin, Adam Kadmon, Aba we Ima, Galgalta we Ejnaim).
- **ד־ (of) → „de“**, lower case, a separate word: Zehn Sefirot de Rosh,
  Massach de Guf, Pe de Rosh, AB de AK, Reshimo de Hitlabshut, Kelim de
  Panim. BB also writes plain German „von“ / genitive in loose prose; inside a
  technical construct always „de“.
- **ו (and) inside a name → „we“**: Aba we Ima (35), Galgalta we Ejnaim (7),
  Israel Saba we Twuna; in the acronyms → u: CHuB, TuM. Never „ve“.
- **The article ה inside a Hebrew name → „ha“ joined to a capital**: Olam haSe,
  Melech haDaat, Talmud Esser haSefirot, Malchut haMessajemet. BB's own spaced
  forms (Midat ha Din, Moach ha Daat, Melech ha Daat) are attested too;
  prefer joined.
- **Genders** (BB's usage): der Parzuf, der Massach, der Siwug, der Zimzum,
  der Bitush, der Rosh, der Guf, der Tabur, der Parssa, der Chase, der Sium,
  der MaH; die Awiut, die Reshimo, die Bchina, die Sefira, die Hisdakchut,
  die Hitkalelut, die Nukwa, die Malchut (sie); das Kli, das Pe, das Hej, das
  Licht, das Or Choser / Or Makif; plural die Kelim, die Mochin.

### 1.4 Quotation marks, glosses, italics

- **Quotes**: German low-high „…“ (621 / 602), inner ‚…‘ (27 / 21).
  Guillemets 0, straight quotes 0. The `”` that appears 18 times is a
  closing-quote slip — use `“`.
- **Glosses**: round brackets after the transliteration, once per item:
  „Massach (Schirm)“ — round brackets 113 : square 28 for these glosses.
  Square brackets mark an editor's insertion, as in BB („GaR [die ersten drei
  Sefirot]“) and as in our source text; keep the source's own brackets as
  they are.
- **No added italics.** BB's Pticha italicises transliterations (Massach 280 of
  284 inside `<em>`), its Intro italicises nothing (0 `<em>`). Our items keep
  only the source's own markup (`<b>` lemmas, `<sup>` footnote markers).
- **Numbers**: Arabic numerals, computed by gematria from the Hebrew letters,
  thousands as in the English rule. Inline Hebrew-letter markers `(ב)` → `(2)`.

### 3.2 Sense splits and false friends

- **Ohr ≠ Or.** „Ohr“ is the German word _ear_ (BB: „Osen (Ohr)“). The light is
  always **Or**. The gate bans „Ohr Pnimi / Ohr Makif …“, never bare „Ohr“.
- **Or Pnimi ≠ Inneres Licht.** _Or Pnimi_ is the technical inner light (27).
  _Inneres Licht_ is the name of Baal HaSulam's commentary (the site's UI
  name). `או"פ` can be either: „(Inneres Licht, Punkt 5)“ is a citation; „Or
  Pnimi und Or Makif“ is the concept.
- **או"ח is Or Choser, never Or Chochma.** Expand `או"ח` → Or Choser (BB 52);
  „Or Chochma“ is only for spelled-out אור חכמה (or אור הח').
- **ZA ≠ SA.** BB writes „(ZA)“ once — for _Zimzum Alef_ (P §22). `ז"א` is
  always **SA** / Seir Anpin. Never abbreviate Zimzum Alef.
- **Stufe for both מדרגה and קומה.** BB writes „die Stufe Keter“ 119 times
  against „das Niveau Keter“ 13. Use Niveau only where the Hebrew sets קומה
  against מדרגה in one sentence.
- **Unterscheidung ≠ Bchina.** Unterscheidung renders `הבחנה` (the act of
  discerning); `בחינה` is Bchina. In the Intro's non-technical prose BB
  renders בחינה as „Stadium“ (50, e.g. „das erste Stadium der Offenbarung des
  Angesichts“) — keep Stadium only for that Providence vocabulary.
- **Otiot vs Buchstaben.** Otiot = the TNTA vessels; Buchstaben = letters of a
  word or name (die vier Buchstaben HaWaYaH).
- **Nekudot vs Punkt.** Nekudot = TNTA / Nekudot de SaG; a single vowel point
  or geometric point → „der Punkt von Cholam“, „der Punkt dieser Welt“. And
  **Punkt N** is the item label — never „Absatz“, „Abschnitt“, „Paragraph“
  (0 each in BB as item labels).
- **Nukwa vs Nekewa.** `נוקבא` → Nukwa (the Partzuf / the female of ZA);
  `נקבה` → Nekewa (the female level in a Rosh, paired with Sachar). As
  adjectives both → weiblich.
- **Raum vs Platz.** `חלל` → Raum (der leere Raum = חלל פנוי); `מקום` → Platz
  (165 : Ort 10). Keep them apart.
- **Gleichheit vs Angleichung der Form.** השתוות (the state) → Gleichheit
  (3 of 3); השוואה (the act) → Angleichung (3).
- **Zerbrechen der Gefäße** is the one fixed name where Gefäße beats Kelim
  (4 : 3). Everywhere else כלים → Kelim.
- **Rashim, not Roshim.** ראשים → Rashim (5 : 3).
- **Welt X / Welt von X / Welt der X.** BB uses all three (Welt Azilut 63 /
  von Azilut 7; Welt Nekudim 7 / von Nekudim 18 / der Nekudim 8). Write
  „die Welt Azilut“, „die Welt Nekudim“ — one form.
- **Wissenschaft vs Weisheit der Kabbala.** חכמת הקבלה → die Wissenschaft der
  Kabbala (24 : 2). But „diese Weisheit“ for החכמה הזאת, and Chochma as a
  Sefira is never translated.

### 3.4 Gate notes

- `required` triggers are heuristics with prefix guards (ודו"ק is not ו"ק,
  תנה"י is not נה"י, הרבה is not הרב, עש"ה is not ע"ש, אותיות / נקראות are not
  אות). Two need reading the sentence: `ע"ב` (Parzuf AB vs folio side b —
  the trigger skips it after a page numeral) and `א"א` (Arich Anpin vs אי
  אפשר, „impossible“).
- `banned` lists only forms with **0** official uses against a counted
  majority; the single exception is `ZA` (1 official hit, the Zimzum Alef
  abbreviation — not to be imitated either).
